01 พื้นฐาน

Blockchain = DLT / Shared Database + Cryptography + Distributed Computing; ข้อมูลร่วมแก้ย้อนหลังยาก
Satoshi Nakamoto → 2008 → Bitcoin
Nick Szabo → 1994 → Smart Contract

4 ขั้นตอน ≠ 4 องค์ประกอบ

Create → Broadcast → Validation → Add to Chain
Block + Chain + Consensus + Validation
Node = อุปกรณ์เครือข่าย (ไม่อยู่ในชุด 4 องค์ประกอบของเล่ม)
Genesis Block = Block แรก

Block / Hash

Header + Data; Timestamp = เวลาสร้าง
Previous Hash = Current Hash ของ Block ก่อน
Nonce = ค่าทดลองค้นหา Hash / Target = เกณฑ์ที่ต้องผ่าน
Merkle Root = Hash สรุป Transactions ทั้ง Block ด้วย Hash Tree
Hash = ทางเดียว + ผลความยาวคงที่
แก้ข้อมูล → Hash เปลี่ยน → จุดเชื่อมถัดไปไม่ตรง; ส่วนถัดไปเปลี่ยนเมื่อคำนวณ Chain ใหม่

Consensus

PoW = งานคณิตศาสตร์ + Miner
PoS = วางสินทรัพย์ + Validator
PoA = ผู้ตรวจสอบได้รับสิทธิ์/เชื่อถือได้
PBFT: n ≥ 3f+1 → f=1:4, f=2:7, f=3:10
Validation = ตรวจตามกฎ / Consensus = ยอมรับร่วมกัน

ประเภท / คุณลักษณะ

Public = Permissionless (Bitcoin/Ethereum)
Private = Permissioned (Hyperledger/Corda)
Consortium = หลายองค์กรเฉพาะกลุ่ม
คุณลักษณะ 3: Integrity / Transparency / Availability
Immutability = ประวัติแก้ย้อนหลังยาก
สร้างข้อมูลองค์กรเดียว → ไม่จำเป็นตามเกณฑ์เล่ม

ประยุกต์ 4 แบบ

Cryptocurrency = Bitcoin/Ripple
Proof of Services = Identity/Ownership/Membership
Proof of Existence = Digest + เวลา
Smart Contract = IF condition THEN execute
เด่น: Security / Automation / Standardization
จำกัด: Human Error / Immutable / Confidence / Cost
Easy to change ไม่ใช่จุดเด่น
DAO = องค์กร/ระบบใช้ Smart Contracts อัตโนมัติ

02 งานบริการภาครัฐ

เป้าหมาย 4

Social Welfare = สวัสดิการ + Identity/Wallet
e-Government = ลดซ้ำ/เชื่อมบริการ
Transparency = ตรวจสอบการใช้จ่าย
National Security = โครงสร้างพื้นฐานสำคัญ

ประโยชน์ / ข้อจำกัด

Transparency + Tamper-Proof
Privacy: Immutability ↔ Right to be Forgotten (GDPR ตามกรณีศึกษา)
Copyright: ข้อมูลละเมิดลบยาก
Censorship: กำกับข้อมูลผิดกฎหมายยาก
คุมสมาชิก/สิทธิ์ในงานรัฐ → พิจารณา Private
ต้นทุน Public บางแบบ: Hardware / Miner / Maintenance / พลังงาน

3 กลุ่มใช้งาน

Identity Management = พิสูจน์ตัวตน
SSI = Self-Sovereign Identity; เจ้าของควบคุมข้อมูลประจำตัว/แบ่งปัน
Illinois → Birth Registration / Citizen ID
UN → ผู้ลี้ภัย/ผู้ประสบภัย

Data Record Management = ทะเบียน/ประวัติ บุคคล องค์กร สินทรัพย์ กิจกรรม
India → Land Registry
Dubai → Electronic Health Record

Transaction Traceability = ตรวจย้อนกลับ Supply Chain
China → Food Safety
India → ยา / Colorado → Industrial Hemp
EU → Tax Compliance/Fraud Detection
Thailand → e-LG (Letter of Guarantee)
เป้า: Transparency / Neutrality / Reliability / Security

3 Governance = กฎหมายและกำกับ
4 Standards = มาตรฐานร่วม
5 Capacity Building = พัฒนาคน

ISO/TC 307 → Blockchain / DLT

03 ภาครัฐไทย / e-Referral

รัฐบาลดิจิทัล 4 เสา

Integration = ข้อมูล/บริการ/งาน; One Stop, Shared Services, Economies of Scale
Smart Operations = เทคโนโลยี + Big Data/Analytics
Citizen-centric = ประชาชน; Security ↔ Facilitation
Driven Transformation = People/Process/Technology/Regulation

9 เทคโนโลยี: VR/AR, AI, Cyber Security, GIS, Cloud, Big Data, Open Any Data, IoT, Blockchain/DLT

ระบบที่อย่าสลับ

e-Authentication = ยืนยันตัวบุคคล / SSO = Login ครั้งเดียว
GDX = แลกข้อมูล/เอกสารทะเบียน
ESB = Enterprise Service Bus; ตัวกลางเชื่อม Web Services
Blockchain Network = P2P + Node + API + Consensus
On-Chain = ข้อมูลจริงบน Chain
Off-Chain = Pointer บน Chain / จริงภายนอก; ไฟล์ X-Ray/MRI ใหญ่

4 ส่วน: Access Control Application / Local Database / Services-Microservices / Blockchain Cluster (Private-Permissioned)
Smart Contract = Business Rules + Workflow + Access Control

ตัวอย่างไทย

สวัสดิการ: Identity+Contract / การศึกษา: Certificate / สุขภาพ: HIE / เกษตร: IoT+Contract / ภัย: IoT+Oracle / จัดซื้อ: Identity+Blacklist+Contract
คนต่างด้าวรักษา: ตม./ตำรวจ/จัดหางาน/รพ./กงสุล → แชร์ข้อมูลตามสิทธิ์ ลดเอกสาร ตรวจย้อนหลัง

ส่งต่อผู้ป่วย / ต้นแบบ 4 Node: รพ.ปฐมภูมิ/ทุติยภูมิ/ตติยภูมิ/ผู้บริหารระบบ; ใช้ข้อมูลสมมติ
Hyperledger Fabric 1.0 = Private/Permissioned, Modular
Chaincode = Smart Contract / Composer = Model+Deploy+REST / ReactJS = Front End
